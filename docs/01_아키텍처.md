# Turborepo Boilerplate Architecture

## 1. 목표

이 보일러플레이트의 목표는 다음과 같습니다.

```txt
프로젝트 초기 세팅을 빠르게 끝낸다.
Next.js 앱 구조를 일관되게 유지한다.
관리자 앱과 서비스 앱의 공통 기반을 제공한다.
백엔드는 DDD에 가까운 계층 구조를 유지한다.
폼, 검증, 에러, 로깅, 테스트, 설정을 표준화한다.
과도한 패키지 분리는 피하되, 나중에 분리 가능한 구조로 시작한다.
```

핵심 방향은 다음입니다.

```txt
Turborepo
+ Next.js App Router
+ Server First
+ 완화된 FSD
+ DDD-style Backend Layering
+ Native Form + Server Actions
+ Zod Validation
+ Result Pattern
+ Structured Logging
+ Vitest + Playwright
```

# 5. Apps 구조: 완화된 FSD

Next.js App Router에서는 전통 FSD를 그대로 적용하면 `app/` 라우팅 구조와 충돌하기 쉽습니다.

따라서 다음처럼 완화된 FSD를 사용합니다.

```txt
apps/web/
├─ actions/
├─ app/
├─ config/
├─ entities/
├─ features/
├─ shared/
└─ views/

apps/admin/
├─ actions/
├─ app/
├─ config/
├─ entities/
├─ features/
├─ shared/
└─ views/
```

## 각 디렉터리 역할

```txt
app
  Next.js routing 전용
  page.tsx, layout.tsx, loading.tsx, error.tsx

views
  페이지 조립 단위
  여러 feature/entity를 조합

features
  사용자 행위 단위
  create-product, update-product, delete-content 등

entities
  도메인 모델 단위 UI/helper
  product, user, order 등

actions
  Server Actions

shared
  앱 내부에서만 공유되는 코드

config
  앱별 설정
```

## export 규칙

패키지 디렉터리 내부의 `client.ts`는 다음과 같이 어디든 쓰여도 상관 없는 파일만 `export` 합니다.

```ts
export * from "./content.constant.ts";
export * from "./content.schema.ts";
export * from "./content.dto.ts";
```

서버에서만 사용되어야 하는 경우, 다음과 같이 `server.ts`로 `export` 합니다.

```ts
import "server-only";

export * from "./content.service.ts";
export * from "./content.mapper.ts";
export * from "./content.permission.ts";
export * from "./content.error.ts";
```

이는 다른 패키지에서도 마찬가지 입니다.

# 7. Backend 구조: DDD-style Layering

기본 흐름은 다음입니다.

```txt
UI
 → Server Action
   → Domain Service
     → Repository
       → Prisma
```

각 계층의 책임은 명확히 나눕니다.

```txt
Server Action
  FormData 처리
  인증/권한 확인
  Zod validation
  service 호출
  revalidate/redirect

Service
  비즈니스 규칙
  비즈니스 검증
  repository 조합
  Result 반환

Repository
  DB 접근
  Prisma query
  Prisma error 변환

Prisma
  실제 DB 처리
```

```ts
import { ListQuery } from "@repo/core/types";

import { CONTENT } from "./content.constant";

export const ContentIdParam = z.object({
  id: z.uuid(),
});

export type ContentIdParamInput = z.infer<typeof ContentIdParam>;

export const ContentListSortKeys = ["TITLE", "CREATED_AT", "UPDATED_AT"] as const;

export type ContentListSortKey = (typeof ContentListSortKeys)[number];

  status?: ContentStatus;

export const CreateContentRequest = z.object({
  title: z
    .string()
    .trim()
    .min(CONTENT.TITLE.MIN_LENGTH, CONTENT.TITLE.MIN_MESSAGE)
    .max(CONTENT.TITLE.MAX_LENGTH, CONTENT.TITLE.MAX_MESSAGE)
    .regex(CONTENT.TITLE.PATTERN, CONTENT.TITLE.INVALID_MESSAGE),

    .max(CONTENT.BODY.MAX_LENGTH, CONTENT.BODY.MAX_MESSAGE),
});

export const UpdateContentRequest = CreateContentRequest.partial();

export type UpdateContentRequestInput = z.infer<typeof UpdateContentRequest>;
```

# 11. `z.coerce`와 `z.preprocess` 사용 기준

Native Form + Server Actions를 쓰면 `FormData` 값은 대부분 문자열입니다.

따라서 숫자, boolean, Date는 변환이 필요합니다.

## 기본은 `z.coerce`

```ts
export const CreateProductRequest = z.object({
  price: z.coerce.number().int().min(PRODUCT.PRICE.MIN, PRODUCT.PRICE.MIN_MESSAGE),
  quantity: z.coerce.number().int().min(PRODUCT.QUANTITY.MIN, PRODUCT.QUANTITY.MIN_MESSAGE),
  visible: z.coerce.boolean(),
  publishedAt: z.coerce.date().optional(),
});
```

## 복잡한 변환은 `z.preprocess`

예: 빈 문자열을 `undefined`로 처리해야 할 때.

```ts
import { z } from "zod";

export const zOptionalNumber = () =>
  z.preprocess((value) => {
    if (value === "") {
      return undefined;
    }

    return Number(value);
  }, z.number().optional());
```

추천 위치:

```txt
packages/core/src/validation/zod-helper.ts
```

예:

```ts
import { z } from "zod";

export const zRequiredString = (message = "필수 입력값입니다.") =>
  z.string().trim().min(1, message);

export const zOptionalString = () =>
  z.preprocess((value) => {
    if (value === "") {
      return undefined;
    }

    return value;
  }, z.string().trim().optional());

export const zOptionalNumber = () =>
  z.preprocess((value) => {
    if (value === "") {
      return undefined;
    }

    return Number(value);
  }, z.number().optional());

export const zFormBoolean = () =>
  z.preprocess((value) => {
    if (value === "on") {
      return true;
    }

    if (value === "true") {
      return true;
    }

    return false;
  }, z.boolean());
```

```ts
import { failure, success, type Result } from "@repo/core/result";
import type { AppError } from "@repo/core/errors";
import { logger } from "@repo/core/logger";
import { createContentRepository, existsContentByTitleRepository } from "@repo/database/content";

import type { CreateContentRequestInput } from "./content.schema";
import type { ContentResponse } from "./content.dto";
import { toContentResponse } from "./content.mapper";

export async function createContentService(
  input: CreateContentRequestInput,
): Promise<Result<ContentResponse, AppError>> {
  const duplicated = await existsContentByTitleRepository(input.title);

  if (!duplicated.ok) {
    return failure(duplicated.error);
  }

  if (duplicated.data) {
    logger.warn("content.title_duplicated", {
      title: input.title,
    });

    return failure({
      code: "CONTENT_TITLE_DUPLICATED",
      message: "이미 사용 중인 제목입니다.",
      fieldErrors: {
        title: ["이미 사용 중인 제목입니다."],
      },
    });
  }

  const created = await createContentRepository(input);

  if (!created.ok) {
    return failure(created.error);
  }

  return success(toContentResponse(created.data));
}
```

# 16. Repository 네이밍

Repository는 **DB 접근만 담당**한다.

Repository의 책임은 다음으로 제한한다.

```txt
Prisma query 실행
DB 입출력 처리
Prisma error → AppError 변환
Result 반환
```

Repository는 `Response DTO`를 반환하지 않는다.
`Response DTO` 변환은 `domain`의 `mapper` 또는 `service`에서 처리한다.

## 파일명

```txt
content.repository.ts
user.repository.ts
```

## 함수명

```txt
create[Domain]Repository
update[Domain]Repository
delete[Domain]Repository
find[Domain]ByIdRepository
find[Domain]sRepository
findAll[Domain]sAndCountRepository
exists[Domain]By[Field]Repository
```

예:

```txt
createContentRepository
updateContentRepository
deleteContentRepository
findContentByIdRepository
findContentByUserIdRepository
findContentsRepository
findAllContentsAndCountRepository
existsContentByTitleRepository
```

## 입력 타입

Repository의 입력 타입은 상황에 따라 다음을 허용한다.

```txt
Prisma.*Input
도메인 schema input
```

생성/수정처럼 Prisma와 거의 1:1로 대응되는 경우에는 `Prisma.Input`을 사용해도 된다.

```txt
Prisma.ContentCreateInput
Prisma.ContentUpdateInput
```

## 출력 타입

Repository는 DB 모델 또는 Prisma payload에 가까운 타입을 반환한다.

```txt
Content
Content | null
Content[]
{ contents: Content[]; totalElements: number }
```

Repository에서 바로 `ContentResponse`, `ContentDetailResponse` 같은 UI/API 응답 DTO를 반환하지 않는다.

응답 DTO 변환은 다음 계층에서 처리한다.

```txt
Repository
  → Prisma Model 반환

Service
  → Mapper 호출

Mapper
  → Response DTO 반환

UI
  → Response DTO 사용
```

## 예시

```ts
import { type Prisma, Content } from "@prisma/client";

import { prisma } from "../client";
import { mapPrismaError } from "../errors";

export async function createContentRepository(data: Prisma.ContentCreateInput): Promise<void> {
  try {
    await prisma.content.create({ data });
  } catch (error) {
    throw mapPrismaError(error);
  }
}

export async function findContentByIdRepository(contentId: string): Promise<Content | null> {
  try {
    const content = await prisma.content.findUnique({
      where: {
        id: contentId,
      },
    });

    return content;
  } catch (error) {
    throw mapPrismaError(error);
  }
}

export async function existsContentByTitleRepository(title: string): Promise<boolean> {
  try {
    const count = await prisma.content.count({
      where: {
        title,
      },
    });

    return count > 0;
  } catch (error) {
    throw mapPrismaError(error);
  }
}
```

# 17. Prisma Error 처리

Prisma 에러는 외부 계층으로 그대로 내보내지 않습니다.

```txt
Prisma Error
 → mapPrismaError()
 → AppError
 → Result
 → ActionResult
```

추천 위치:

```txt
packages/database/src/errors/prisma-error.mapper.ts
```

예:

```ts
import { Prisma } from "@prisma/client";

import { type AppError } from "@repo/core/errors";

export function mapPrismaError(error: unknown): AppError {
  if (error instanceof Prisma.PrismaClientKnownRequestError) {
    switch (error.code) {
      case "P2002":
        return {
          code: "DATABASE_UNIQUE_CONSTRAINT",
          message: "이미 존재하는 데이터입니다.",
          cause: error,
        };

      case "P2003":
        return {
          code: "DATABASE_FOREIGN_KEY_CONSTRAINT",
          message: "연결된 데이터가 올바르지 않습니다.",
          cause: error,
        };

      case "P2025":
        return {
          code: "DATABASE_RECORD_NOT_FOUND",
          message: "대상을 찾을 수 없습니다.",
          cause: error,
        };

      default:
        return {
          code: "DATABASE_KNOWN_ERROR",
          message: "데이터 처리 중 오류가 발생했습니다.",
          cause: error,
        };
    }
  }

  if (error instanceof Prisma.PrismaClientValidationError) {
    return {
      code: "DATABASE_VALIDATION_ERROR",
      message: "데이터 형식이 올바르지 않습니다.",
      cause: error,
    };
  }

  return {
    code: "DATABASE_UNKNOWN_ERROR",
    message: "데이터 처리 중 알 수 없는 오류가 발생했습니다.",
```

# 22. Zod Error Mapper

```ts
import type { ZodError } from "zod";

export function mapZodErrorToFieldErrors(error: ZodError): Record<string, string[]> {
  const fieldErrors: Record<string, string[]> = {};

  for (const issue of error.issues) {
    const field = issue.path.join(".");

    if (!fieldErrors[field]) {
      fieldErrors[field] = [];
    }

    fieldErrors[field].push(issue.message);
  }

  return fieldErrors;
}
```

# 23. Server Action Wrapper

추천 위치:

```txt
packages/core/src/action/create-action.ts
```

예:

```ts
import { z } from "zod";

import type { Result } from "../result";
import type { AppError } from "../errors";
import type { ActionResult } from "./action-result";
import { mapZodErrorToFieldErrors } from "../validation";
import { logger } from "../logger";

export async function createAction<TInput, TData>(params: {
  actionName: string;
  schema: z.ZodSchema<TInput>;
  formData: FormData;
  handler: (input: TInput) => Promise<Result<TData, AppError>>;
  successMessage?: string;
}): Promise<ActionResult<TData>> {
  const { actionName, schema, formData, handler, successMessage } = params;

  try {
    const raw = Object.fromEntries(formData.entries());
    const parsed = schema.safeParse(raw);

    if (!parsed.success) {
      return {
        ok: false,
        code: "VALIDATION_ERROR",
        message: "입력값을 확인해 주세요.",
        fieldErrors: mapZodErrorToFieldErrors(parsed.error),
      };
    }

    const result = await handler(parsed.data);

    if (!result.ok) {
      logger.warn(`${actionName}.failed`, {
        code: result.error.code,
        message: result.error.message,
      });

      return {
        ok: false,
        code: result.error.code,
        message: result.error.message,
        fieldErrors: result.error.fieldErrors,
      };
    }

    logger.info(`${actionName}.succeeded`);

    return {
      ok: true,
      data: result.data,
      message: successMessage,
    };
  } catch (error) {
    logger.error(`${actionName}.unexpected_error`, {
      error,
    });

    return {
      ok: false,
      code: "INTERNAL_SERVER_ERROR",
      message: "요청 처리 중 오류가 발생했습니다.",
    };
  }
}
```

```ts
export interface PaginationMeta {
  page: number;
  limit: number;
  totalCount: number;
  totalPages: number;
  hasNextPage: boolean;
  hasPreviousPage: boolean;
}

export function createPagination(input: PaginationInput) {
  const page = Math.max(input.page ?? 1, 1);
  const limit = Math.min(Math.max(input.limit ?? 20, 1), 100);
  const skip = (page - 1) * limit;

  return {
    page,
    limit,
    skip,
    take: limit,
  };
}

export function createPaginationMeta(params: {
  page: number;
  limit: number;
  totalCount: number;
}): PaginationMeta {
  const totalPages = Math.ceil(params.totalCount / params.limit);

  return {
    page: params.page,
    limit: params.limit,
    totalCount: params.totalCount,
    totalPages,
    hasNextPage: params.page < totalPages,
    hasPreviousPage: params.page > 1,
  };
}
```

```tsx
import { type ButtonHTMLAttributes, type CSSProperties, forwardRef } from "react";

export type SquareButtonVariant = "primary" | "normal" | "reverse" | "outline" | "error-outline";

export type SquareButtonSize = "xsmall" | "small" | "normal";

export type SquareButtonGrid = {
  colNum: number;
  span: number;
};

export interface SquareButtonBaseProps extends Omit<
  ButtonHTMLAttributes<HTMLButtonElement>,
  "className"
> {
  variant?: SquareButtonVariant;
  size?: SquareButtonSize;
  active?: boolean;
  wide?: boolean;
  grid?: SquareButtonGrid;
  className?: string;
  isToggleButton?: boolean;
}

function buildGridStyle(grid: SquareButtonGrid | undefined): CSSProperties | undefined {
  if (!grid) {
    return undefined;
  }

  return {
    gridColumn: `${grid.colNum} / span ${grid.span}`,
  };
}

export const SquareButtonBase = forwardRef<HTMLButtonElement, SquareButtonBaseProps>(
  (
    {
      variant = "normal",
      size = "normal",
      active = false,
      wide = false,
      grid,
      disabled,
      className,
      style,
      isToggleButton = false,
      type,
      ...rest
    },
    ref,
  ) => {
    const gridStyle = buildGridStyle(grid);

    const mergedStyle: CSSProperties = {
      ...(style ?? {}),
      ...(gridStyle ?? {}),
      ...(wide ? { width: "100%" } : {}),
    };

    const safeType = type ?? "button";

    return (
      <button
        ref={ref}
        type={safeType}
        className={className}
        style={mergedStyle}
        disabled={disabled}
        data-variant={variant}
        data-size={size}
        data-active={active ? "true" : "false"}
        data-wide={wide ? "true" : "false"}
        data-disabled={disabled ? "true" : "false"}
        aria-pressed={isToggleButton ? active : undefined}
        {...rest}
      />
    );
  },
);
```
